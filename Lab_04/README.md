# Lab 04: Wireless LAN using Access Point

## Question

Configure secure wireless access using an access point.

## Objective

Configure SSID `CCNA_LAB`, WPA2-PSK security, DHCP addressing, and wireless client connectivity.

## Main Tasks

1. Configure SSID as `CCNA_LAB`.
2. Configure WPA2 security.
3. Configure DHCP.
4. Connect wireless devices.
5. Browse the web server.
6. Test signal strength.

## Challenge

Create two SSIDs:

- `Faculty`
- `Guest`

Allow Guest users to access only the Internet.
