# Lab 05: Cellular Network

## Question

Connect mobile devices through the Packet Tracer cellular network.

## Objective

Register mobile devices with the cellular tower, configure DNS, browse a web server, and compare Wi-Fi and cellular access.

## Main Tasks

1. Register smartphones and tablets.
2. Configure DNS.
3. Browse the web server.
4. Compare Wi-Fi access and cellular access.

## Challenge

Allow only Smartphone1 to access the web server.
