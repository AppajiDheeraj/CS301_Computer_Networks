# Lab 03: DHCP and DNS Server

## Question

Configure automatic IP addressing and hostname resolution using DHCP and DNS services.

## Objective

Configure a DHCP/DNS server, web server, DNS entries, DHCP pool, and reserved IP address for PC1.

## Addressing Plan

| Device | IP Address |
| --- | --- |
| DHCP/DNS Server | `192.168.1.2` |
| Web Server | `192.168.1.3` |
| PC1 | DHCP reserved address |
| PC2 | DHCP |
| PC3 | DHCP |

## Main Tasks

1. Configure DHCP pool.
2. Configure DNS entries such as `www.company.com`, `ftp.company.com`, and `mail.company.com`.
3. Configure web server service.
4. Access website using `www.company.com`.
5. Reserve an IP address for PC1.
