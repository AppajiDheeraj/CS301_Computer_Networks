# Lab 06: Enterprise Campus Network

## Question

Build a complete enterprise campus network using VLANs, routing, services, wireless, and cellular connectivity.

## Objective

Combine the concepts from earlier labs into a larger campus topology with Admin, Faculty, and Student VLANs, DHCP, DNS, HTTP, wireless, cellular, ACLs, and end-to-end verification.

## Main Tasks

1. Configure VLANs and trunk links.
2. Configure Router-on-a-Stick.
3. Configure DHCP for all VLANs.
4. Configure DNS and web server.
5. Configure access point.
6. Register smartphones with the cellular tower.
7. Verify end-to-end connectivity.

## Challenge Rules

- Students cannot access Admin VLAN.
- Faculty can access all servers.
- Guest Wi-Fi users can access Internet only.
- Cellular users can browse website but cannot access internal PCs.
