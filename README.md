# CS301 Computer Networks

This repository contains CS301 Computer Networks lab assignments and Packet Tracer notes.

## Software Needed

- Cisco Packet Tracer
- Optional: Wireshark for extra packet-analysis practice

Cisco Packet Tracer is not available through Homebrew on macOS. Download it from Cisco Networking Academy:

- Packet Tracer page: https://www.netacad.com/cisco-packet-tracer
- Resource Hub downloads: https://www.netacad.com/resources/lab-downloads

Setup status on this Mac: Packet Tracer was not found in `/Applications`. Cisco requires the NetAcad/Skills for All sign-in flow for the installer, so the final download needs your Cisco account login.
