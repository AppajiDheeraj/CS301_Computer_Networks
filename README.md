# CS301 Computer Networks

This repository contains Cisco Packet Tracer lab work for CS301 Computer Networks. The structure is kept simple and exam-friendly: each assignment has its own `Lab_XX` folder with the question, required topology, configuration steps, verification, and short answers.

## Software Needed

- Cisco Packet Tracer
- Optional: Wireshark for real packet capture practice

Cisco Packet Tracer is not available through Homebrew on macOS. Download it from Cisco Networking Academy:

- Packet Tracer page: https://www.netacad.com/cisco-packet-tracer
- Resource Hub downloads: https://www.netacad.com/resources/lab-downloads

Cisco currently distributes Packet Tracer through NetAcad/Skills for All, and the Resource Hub lists builds for Windows, macOS, and Ubuntu. On macOS, download the `.dmg`, open it, drag Packet Tracer to Applications, and sign in with a Cisco/NetAcad account when prompted.

Setup status on this Mac: Packet Tracer was not found in `/Applications` during repo setup. Because Cisco requires a NetAcad download/sign-in flow, install it manually from the official link above, then save your `.pkt` files inside the matching lab folder.

## Exam Preparation Pattern

For each lab, revise these points:

1. Objective of the topology.
2. Devices used.
3. IP addressing table.
4. Router, switch, server, or wireless configuration.
5. Verification commands and expected output.
6. Short explanation of the networking concept.
